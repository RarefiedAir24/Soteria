# Unit API Token Description

## Recommended Description

### Option 1: Simple & Clear
```
Goal-based savings accounts - Sandbox
```

### Option 2: More Descriptive
```
Soteria goal savings accounts - Sandbox testing
```

### Option 3: Detailed
```
Goal-based savings accounts for Soteria app - Sandbox environment
```

### Option 4: With Purpose
```
Create and manage goal savings accounts - Sandbox
```

---

## Best Practice

**Use**: `Goal-based savings accounts - Sandbox`

**Why:**
- ✅ Clear purpose (goal savings)
- ✅ Indicates environment (sandbox)
- ✅ Short and descriptive
- ✅ Easy to identify later

---

## For Production Token (Later)

When you create a production token, use:
```
Goal-based savings accounts - Production
```

Or:
```
Soteria goal savings - Production
```

---

## Token Naming Convention

You might create multiple tokens:
- `Goal savings - Sandbox` (testing)
- `Goal savings - Production` (live)
- `Goal savings - Development` (if you have dev environment)

This helps you identify which token is which later.
